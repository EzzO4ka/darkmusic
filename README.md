# 🎧 DARK MUSIC — Эксклюзивный музыкальный стриминг

> **Dark Music** — персональное Android-ориентированное веб-приложение для прослушивания музыки в глубоком чёрном AMOLED-дизайне. Полностью синхронизировано с репозиторием GitHub, поддерживает файлы с русскими именами и оснащено панелью администратора с живыми уведомлениями и управлением версиями.

---

## ⚡ Ключевые возможности

### 📱 Интерфейс и звук
- **AMOLED Dark UI**: Чистый чёрный фон (`#000000`), неоновые акценты и пружинящий отклик интерфейса на нажатия (`spring-btn`).
- **Бесшовное воспроизведение (Zero-Flicker)**: Плавное переключение треков и паузы без мерцания или повторной загрузки обложек. Картинки кэшируются в памяти.
- **Режим «Моя волна»**: Моментальный старт воспроизведения всего каталога треков вперемешку.
- **Полноэкранный AMOLED-плеер**:
  - Анимированная квадратная обложка альбома/трека.
  - Точный таймлайн с перемоткой.
  - Интерактивный блок **«Интересный факт об артисте»**, сменяющийся прямо во время воспроизведения.
  - Резервный синтезатор баса (воспроизводит звук, даже если MP3-файл ещё загружается на сервер).

### 📢 Уведомления и контроль версий (Live Push)
- **Всплывающее уведомление на 20 секунд**: Показывается слушателю при входе с плавной анимацией и полосой обратного отсчета, после чего автоматически исчезает.
- **Закреплённый баннер**: Висит в верхней части экрана приложения у всех пользователей до момента отмены владельцем.
- **Принудительное обновление (Kill-Switch старых версий)**: Блокирует доступ к приложению для устаревших сборок с выводом сообщения и прямой ссылки на скачивание новой версии. Для владельца предусмотрен обход блокировки по PIN-коду.

## 📁 Структура репозитория

Для корректной подгрузки файлов в репозитории `EzzO4ka/darkmusic` используется структура:

```text
├── avatars/                # Фотографии артистов лейбла
│   ├── mc_geich.jpg        # Фото МС ГЕИЧ
│   ├── mc_makaka.jpg       # Фото МС МАКАКА
│   ├── mc_ezdit.jpg        # Фото МС ЕЗДИТЬ
│   └── mc_oparysh.jpg      # Фото МС ОПАРЫШ
│
├── covers/                 # Обложки релизов и альбомов (.jpg / .png)
│   ├── alb_zageev.jpg      # Обложка альбома «ЗАГЕЕВ»
│   └── ...                 
│
├── tracks/                 # Аудиофайлы треков (.mp3)
│   ├── Черный сервер.mp3   # Поддерживаются файлы с русскими именами
│   └── ...
│
├── catalog.json            # Единая база треков, альбомов и уведомлений
└── index.html              # Автономный файл приложения Dark Music
```

## 🚀 Быстрый старт

### Для слушателей:
1. Откройте `index.html` в браузере мобильного устройства или перейдите по ссылке GitHub Pages.
2. Приложение готово к работе: каталог, альбомы и фото артистов подтягиваются автоматически.

### Для владельца:
1. Нажмите на иконку замка в шапке или перейдите на вкладку **«Владелец»** в нижнем меню.
2. Введите секретный PIN-код: **`4681`**.
3. Добавляйте треки, создавайте альбомы или отправляйте уведомления слушателям — изменения синхронизируются через GitHub API.
4. Для раздачи обновлений друзьям воспользуйтесь кнопкой **«Скачать готовый index.html»** в панели управления.
